# 02 · Super Hearing — prompts

**Context:** You joined Rook two weeks ago as PM on Dispatch.
Release 4.2 shipped on 12 August, just before you arrived, and
landed badly. Last session you built a context file and met the
company.

You still do not know what actually went wrong.

At the end of the session, ask Claude Code to save the prompts you
wrote yourself below — not the starter prompt. The closing slide has
the exact prompt to paste. By Module 6 this file is a prompt library
built from your own questions.

---

### 1.

```
Read everything in 00-rook/feedback/interviews/. These are four conversations with the people who run the console for our responders. Tell me what they're unhappy about, group it, tell me how many of the four raised each thing, and quote one line for each so I can hear how they actually said it.
```

### 2.

where are the problem tickets ? and the interviews with the customers ? add these to Claude.md file so that you can easily find them later

### 3.

Read everything in Customer interviews. These are four conversations with the people who run the console for our responders. Tell me what they're unhappy about, group it, tell me how many of the four raised each thing, and quote one line for each so I can hear how they actually said it.

### 4.

Is there a common theme within the interviews, that I can take it further

### 5.

Any specific issues with the new features that were introduced and I should worry about

### 6.

```
Read everything in Tickets. Same treatment as before: group them, tell me how many are in each group, and quote one line from each.
```

### 7.

### 8.

```
Only look at what came in after 13 August. What's different about these compared to everything before?
```

### 9.

Are there common themes between the Interview and Tickets that is related and any key take aways - give me a table summary

### 10.

```
If both piles are telling the truth, how can they both be right?
```
